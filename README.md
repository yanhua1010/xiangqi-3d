# 3D 中国象棋 · Xiangqi 3D

一款运行在浏览器中的 3D 中国象棋。基于 [rork-medieval-3d-chess](https://github.com/alexngdev99/rork-medieval-3d-chess)
（国际象棋 3D 版）的技术思路复刻，使用 **Vite + React 19 + TypeScript + Three.js** 构建，
规则与 AI 完全自研，无需后端、无账号、纯静态站点。

![tech](https://img.shields.io/badge/Vite-8.x-646cff) ![react](https://img.shields.io/badge/React-19-61dafb) ![three](https://img.shields.io/badge/three.js-0.185-000)

## 特性

- **完整中国象棋规则**：车、马、炮、相/象、仕/士、帅/将、兵/卒的走法；马腿、象眼、炮架；
  九宫限制、相不过河、兵过河可横走；**将帅不照面**；将军与将死判定。
- **3D 武将棋子（程序化建模）**：每个棋子都是一个小武将/战器——
  帅披紫金披风挂玉带珠串、仕执羽扇、象是带分节象鼻和象牙的战象、马带鬃毛尾巴、
  车是插旗战车带八辐车轮、炮是带炮口焰与引信火花的青铜炮车、兵是持枪披甲士兵；
  行军时双腿摆动、车轮转动、象鼻卷动、披风飘动、马头晃动，静止时也有呼吸式待机。
  参考了开源 3D 象棋项目的角色表现手法。
- **5 套棋子材质皮肤**：实木经典、温润玉石、青铜古战场、青花瓷器、金漆宫廷——同一造型切换材质配色，运行时一键更换。
- **4 套棋盘环境主题**：经典木盘、玉盘（发光玉珠）、青铜沙盘（四角烽火台灯笼+点光源）、水墨宣纸；
  每套同时改变盘面、边框、网格、楚河汉界、光照、天空雾色与环境氛围音。
- **完整合成音效引擎**（Web Audio，零音频文件）：
  - 选子、UI 点击、落子木击（按棋子轻重不同音高）、走子 whoosh、炮口轰鸣
  - 吃子金属碰撞 + 碎裂、**将军铜锣 + 低频警示**
  - 开局鼓点、胜利 fanfare、失败收束、环境底噪（微风/古战场远鼓），3D 声像
- **Three.js 交互相机**：鼠标拖拽旋转视角、滚轮缩放，点击选子，绿点（移动）/红圈（吃子）高亮，
  被将军时红色脉冲圈标记。
- **内置 AI 对手**：Alpha-Beta 剪枝 Negamax + 位置评估表，三档难度（深度 2/3/4），Web Worker 运行。
- **人机对战 / 双人同机**；可执红或执黑，主菜单选择后点「开始游戏」进入。
- **AI 推荐走法**：轮到玩家时引擎评估并推荐 3 个最佳走法（标准中文记法，如「炮二平五」「马八进七」），点击即落子。
- 实时走棋记录（中文记法）、行棋方、将军/思考状态。

## 快速开始

```bash
bun install      # 或 npm install / pnpm install
bun run dev      # 启动开发服务器
bun run build    # 类型检查 + 生产构建，输出到 dist/
bun run preview  # 预览生产构建
```

## 操作

- **左键点击** 棋子选中，再点击高亮落点走棋
- **按住拖拽** 旋转 3D 视角
- **滚轮** 缩放
- 红方先手；执黑时镜头自动转到黑方一侧

## 项目结构

```

├── game/
│   ├── types.ts        # 共享类型：棋子、棋盘、走法、难度

│   └── ai.worker.ts    # Web Worker 封装
├── audio/
│   └── SoundEngine.ts  # Web Audio 合成音效（选子/落子/吃子/将军/胜负/环境音）
├── scene/
│   ├── XiangqiScene.ts # Three.js 场景：棋盘/光照/相机/拾取/行军动画/主题
│   ├── warriors.ts     # 7 种武将与战器的程序化建模 + 行军/待机动画 + 皮肤换色

├── main.tsx
└── index.css
```

## 规则实现说明

- 走法生成采用"伪合法 → 过滤"两步：先生成所有符合子力走法的目标格，再执行走法并检查
  己方是否被将军、以及将帅是否照面，过滤掉非法走法。
- "飞将"（将帅不照面）作为硬性规则：若双方将帅在同一列且中间无子，任何导致该局面的走法均非法。
- 将死/困毙均判负（无合法走子的一方告负），这是中国象棋通行规则。
- AI 使用 Negamax + Alpha-Beta，按吃子价值排序走法以提升剪枝效率；简单难度加入随机扰动。
