# 楚河漢界 · 三維國風象棋

这是一个可直接部署的纯静态 3D 中国象棋网页，完整复刻参考站的国风开场、战场环境、3D 棋子、灯笼旌旗、棋谱面板和交互流程。

## 已实现

- 水墨江山开场：书法标题、印章式「开战」按钮、字体与入场动画
- Three.js 程序化 3D 棋盘与棋子：帅/将、仕/士、相/象、马、车、炮、兵/卒
- PBR 釉彩棋子、棋盘木纹、楚河汉界、宫格与落点高亮
- 远山、日轮、雾气、地面、边界旌旗、四角灯笼、环境花瓣与粒子效果
- 完整中国象棋规则：马腿、象眼、炮架、九宫、相不过河、兵过河、将帅不照面、将军/将死
- 人机对弈 / 双人对弈，入门 / 进阶 / 高手三档 AI
- 新对局、悔棋、红黑双方状态、吃子托盘、棋谱、优势提示
- 推荐下一步：实时计算当前局面的前三个候选走法，显示中文棋谱、评估分，点击即可采用
- 电影运镜（右上角「运镜」按钮，开启后镜头自动环游）、鼠标拖拽旋转、滚轮缩放
- 5 套可实时切换的棋子皮肤：朱砂墨玉、青花瓷影、翡翠赤金、玄铁战痕、金漆宫廷
- 5 套可实时切换的棋盘/环境皮肤：暖木战场、青玉云台、水墨宣纸、朱阙丹霞、青铜古阵；同步改变盘面纹理、边框、楚河汉界、雾色、灯光和灯笼颜色
- 古筝/鼓点氛围音乐与选子、落子、吃子、将军、胜负等音效；界面提供统一音频开关，快捷键仍可分别控制音乐和音效
- 帮助弹窗与键盘快捷键：`N` 新局、`U` 悔棋、`M` 音乐、`S` 音效、`C` 电影运镜、`Esc` 取消选中

## 本地运行

```bash
bun install       # 或 npm install
bun run dev
bun run build
bun run preview
```

入口是 `index.html`，运行时资源位于 `public/`，可作为静态站点部署到 GitHub Pages、Vercel 或任意 CDN。

## 目录说明

- `public/kimi-app.js`：本地化的 3D 游戏运行时
- `public/kimi-app.css`：国风界面、开场和弹窗样式
- `public/recommend.js`：可读的浅层局面评估与前三推荐走法模块
- `public/skins.js`：棋子材质皮肤切换面板与持久化配置
- `public/board-skins.js`：棋盘纹理、盘座、雾色、灯光与环境皮肤切换
- `public/*.woff2`：书法标题与正文中文字体
- `src/`：此前的 TypeScript/Three.js 象棋实验实现，仍保留用于后续拆分和二次开发；生产入口使用 `public/` 中的完整参考复刻运行时
